# web-ssr（二期选修）

SSR / 官网向。对接或展示 `../../server` 的公开内容。

## 技术选型（二选一，不要两个都深挖）

| 选项 | 栈 | 适合 |
|------|-----|------|
| A | **Nuxt 3/4** + Vue | 与 web-pc 同生态，迁移成本低 |
| B | **Next.js** + React | 与 web-admin 同生态，国际岗位多见 |

选定一个写进本目录即可。

## 建议练什么

1. 官网落地页 SSR / SSG
2. 与 SPA（web-pc）对比：首屏、SEO、数据获取方式
3. 可选：部分页面调公开/半公开 API（如健康检查、内容接口）

## 何时开始

一期五端主流程跑通、部署过一次之后。

## 状态

目录预留，未初始化代码。
