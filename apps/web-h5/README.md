# web-h5

移动端 H5（深链 / 轻量操作）。对接 `../../server`。

## 技术栈

| 类别 | 选型 |
|------|------|
| 框架 | Vue 3 |
| 构建 | Vite |
| 语言 | TypeScript |
| 路由 / 状态 | Vue Router + Pinia |
| 请求 | Axios |
| UI | **Vant 4** |
| 适配 | viewport / `postcss-px-to-viewport`（任选） |

## 与其它端分工

| 端 | 场景 |
|----|------|
| web-pc | 桌面完整业务 |
| **web-h5** | 手机浏览器 / 微信内打开、分享落地 |
| web-app | 小程序安装态、原生能力 |

## 建议功能

1. 移动登录页
2. 待办列表 + 快捷改状态（接口就绪后）
3. 深链落地：`/h5/tasks/:id`
4. （进阶）微信网页授权
